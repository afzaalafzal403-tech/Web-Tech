# TailorPro Landing Page - Express Application

This is the TailorPro landing page converted to run as an Express.js application.

## Installation

1. Ensure Node.js is installed on your system.
2. Navigate to the project directory: `cd "d:\Assignment 2\Lab task 2"`
3. Install dependencies: `npm install`

## Running the Application

Start the server with: `npm start`

Or directly: `node server.js`

The application will be available at `http://localhost:3000`

## Features

- Static file serving for CSS, images, and HTML
- Express server setup
- Responsive landing page for TailorPro tailoring services

## Project Structure

- `server.js` - Express server configuration
- `index.html` - Main landing page
- `style.css` - Stylesheet
- `images/` - Image assets
- `package.json` - Project dependencies
